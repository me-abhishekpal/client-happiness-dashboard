# The Idea Forge ⚡

An app to capture, validate, and roast your startup ideas.

## Core Loop
1.  **Capture:** Quick dump of the idea (Problem, Solution, Target Audience).
2.  **Research (The Agent):**
    *   Scours the web for competitors.
    *   Checks search volume/trends.
    *   Identifies "Why now?" (Market timing).
3.  **Verdict (The Judge):**
    *   **Virality Score:** 0-100.
    *   **The Kill Switch:** Reasons *not* to build it.
    *   **The Growth Loop:** How it actually spreads (if it survives).

## Tech Stack (Proposed)
-   **Frontend:** Next.js + Tailwind (Clean, fast UI).
-   **Backend:** Next.js API Routes.
-   **Database:** SQLite (Local/Lightweight) or Supabase (Scalable).
-   **Intelligence:** Gemini/OpenAI API (for the research/analysis).
-   **Search:** Brave Search API (for real-time competitor checking).

## MVP Features
-   [ ] **Dashboard:** List of all ideas with status (Raw, Validating, Killed, Gold).
-   [ ] **Idea Form:** Input fields for the core concept.
-   [ ] **Research Report:** A generated page showing competitors and analysis.
