# Client Happiness Tracker (RAG)

Replacing manual Excel status tracking with an automated, high-visibility dashboard.

## Context
-   **Industry:** Higher Ed IT Outsourcing.
-   **Current State:** Excel sheet, manual updates, chasing people.
-   **Goal:** Streamline updates, visualize health, automate reminders.

## Key Features
1.  **RAG Dashboard:** Instant visual of all client health statuses.
2.  **Automated Nagging:** System emails/slacks the owners for updates (so you don't have to).
3.  **Trend Analysis:** "Client X has been Amber for 3 weeks - why?"
4.  **Audit Trail:** Who changed the status and when?

## Data Structure (Pending Excel Analysis)
-   *Client Name*
-   *Status (Red/Amber/Green)*
-   *Last Updated*
-   *Owner*
-   *Issues/Notes*
